Скрипторий
Творческая мастерская для писателей.
Скрипторий - это редактор, который объединяет в одном месте написание текста, визуализацию структуры истории и много, много ещё разного. 
Проект активно разрабатывается. Текущая версия - веб-прототип (один HTML-файл), в планах - самостоятельное desktop-приложение.
Технологии. 
•	Сейчас: чистый HTML / CSS / JavaScript, без зависимостей от фреймворков
•	JSZip (MIT) - для работы с архивами
•	В планах: обёртка на .NET (WPF/WinForms) + WebView2 для самостоятельного desktop-приложения
