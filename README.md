# Скрипторий

Скрипторий - Ваша мастерская для ваших идей. инструмент для писателей: текстовый редактор, конструктор диаграмм и куча всего разного. В разработке.

Скрипторий Творческая мастерская для писателей. Скрипторий - это редактор, который собирается в одном месте для написания текста, визуализации структуры истории и много-много ещё разного. Проект активно разрабатывается. Текущая версия - веб-прототип (один HTML-файл), в планах - самостоятельное десктоп-приложение.

Технологии.
• Сейчас: чисто HTML/CSS/JavaScript, без зависимости от фреймворков
• JSZip (MIT) - для работы с архивами
• В планах: обёртка на .NET (WPF/WinForms) + WebView2 для самостоятельного настольного приложения
